# Workout Planner

Workout Planner is a weekly training planning app for coaches and athletes.

It is designed to replace spreadsheet-based planning with a clearer workflow for building and following structured training weeks.

## What It Does

- Lets a coach plan training sessions for athletes
- Supports session templates for repeated workout structures
- Gives athletes a clean weekly view of their plan
- Lets athletes mark sessions done and leave notes or adjustments

## Current Focus

The current version is centered around:

- weekly planning
- coach-managed athlete plans
- simple, readable session overviews
- structured workout details inside each session
