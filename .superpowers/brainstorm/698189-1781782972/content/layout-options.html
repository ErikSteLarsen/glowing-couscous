Which app shell feels right?

Goal: less centered SPA feel, clearer nav, predictable back flow.

Option A — Full app shell
Top utility bar
Logo
Dashboard
Planner
Templates
Settings
Sign out
Wide page header

Context back link on detail pages

Main content uses full desktop width

Persistent sidebar shell

One signed-in frame. Sidebar owns global nav. Detail pages keep one local back link.

Option B — Slim rail + content
Icons
Wide content area

Page header actions stay top-right

Labels hidden until hover/open

Slim rail

More room for content. Faster to scan once learned. Less explicit for new users.

Option C — Section shells
Role header
Coach-only or athlete-only nav
Different shell per area

Can tune each role harder

More code paths

Separate shells by section

Highest flexibility. Most maintenance. Risk less consistency.
