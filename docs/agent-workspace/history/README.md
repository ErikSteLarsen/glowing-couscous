# History

History is append-only. Add one dated Markdown file when an agent changes
behavior, architecture, a significant status, or a decision. Include the
agent/date, feature IDs, files, observed behavior, verification commands, and
follow-up work.

Do not use history as the current task board. Read `CURRENT-STATUS.md` and
`WORK-INDEX.md` for current state, then use history to understand how a choice
or implementation arrived there.
